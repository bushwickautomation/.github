# Bushwick Automation

Making AI easier to deploy in the real world.

We’re focused on LLM inference at the edge: running useful models on local devices and nearby compute.

## What we’re exploring

- Inference runtimes and deployment tooling
- Model efficiency, quantization, and hardware tradeoffs
- Evaluation under real device constraints
- Post-training and reinforcement learning for practical workloads

This organization is the home for our development work and experiments as we turn that research into practical tools.
